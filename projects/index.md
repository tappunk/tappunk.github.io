# Projects

## tnk

Local AI sandbox. Inference on the host. Agents in per-project VMs.

- [Docs](/tnk/) · [Source](https://github.com/tappunk/tnk) · [Specs](https://github.com/tappunk/tnk-specs)

## Toolchain

- [gre](https://github.com/tappunk/gre): parallel git status
- [gsty](https://github.com/tappunk/gsty): Ghostty theme browser
- [utmd](https://github.com/tappunk/utmd): UTM VM manager

## Install

```bash
brew tap tappunk/tap
brew install tappunk/tap/gre
brew install tappunk/tap/gsty
brew install tappunk/tap/tnk
brew install tappunk/tap/utmd
```
