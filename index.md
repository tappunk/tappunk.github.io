## Experiments

- [tnk](/tnk/): Zero-trust sandbox for local AI agent runtimes
- [utmd](https://github.com/tappunk/utmd): Disposable VM manager for UTM
- [gsty](https://github.com/tappunk/gsty): Ghostty theme browser
- [gre](https://github.com/tappunk/gre): Parallel git status aggregator

## Install

```bash
brew tap tappunk/tap
brew install tappunk/tap/tnk
tnk init && tnk run
```
